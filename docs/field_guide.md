# DyscalcBattery — Field guide (one page)

Print this page and keep it with the laptop.

## The evening before
- [ ] Laptop fully charged. Charger in the bag.
- [ ] Open `dyscalculia_battery.html` in Google Chrome. All three ticks under **Check this laptop** are green.
- [ ] Practise once in **Training mode** (Advanced → tick Training mode → Visit 1). It takes 3 minutes.
- [ ] Stickers on the keyboard: **green on F**, **blue on J** (match the colours on screen).
- [ ] USB drive, printed consent list, participant log sheet, stickers/pencils for the children.

## For every child
1. Check the child's name is on the **consent list**. If not, do not test.
2. Read the **assent script**. Continue only if the child says yes.
3. On the setup screen: your initials, school code, **participant number** (from the log sheet), class, age, sex. Tick both boxes.
4. Look at the line that says **Participant ID: WRG_0xx**. Check it matches the log sheet. A yellow warning means that number was already used on this laptop: check before continuing.
5. Press **Visit 1** (first meeting) or **Visit 2** (second meeting).
6. At each task, read the **blue box** aloud. Point to the green key for LEFT and the blue key for RIGHT.
7. Practice gives ticks and crosses. If the child struggles, the practice repeats once by itself.
8. Between tasks, let the child rest. Praise effort, never accuracy.
9. At the end you see a green **Session finished and saved**. Write the file name on the log sheet.

## If something goes wrong
| Problem | What to do |
|---|---|
| Child upset or wants to stop | Hold **Shift**, press **Q**, confirm. Data so far is saved. Thank the child. |
| Laptop switched off / browser closed | Reopen the file. Under **Saved sessions** the session shows *interrupted*: press **Download**. Do not restart the same visit the same day; write a note on the log sheet. |
| File did not appear in Downloads | Press **Download again** on the end screen, or use **Saved sessions**. |
| Yellow warning: picture icons do not display | Use Google Chrome. If it still fails, skip "More things" and tell the supervisor. |
| Child presses keys randomly | Pause between tasks, re-explain with your finger on the keys. Note it on the log sheet. |
| Child says the number before pressing SPACE (How many dots) | Remind: "press SPACE first, then tell me". Click what the child said. |
| You could not hear the number | Click **Not sure**. |

## End of every day
1. Copy all files from **Downloads** (names start with `WRG_`) to the USB drive.
2. Upload the same files to the shared Google Drive folder.
3. Delete `DEMO_` files; they are practice only.
4. Send the supervisor a message: number of children tested, any problems.
